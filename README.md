# ⚙️ Run Locally

### Requirements

- Node.js 20+

### Clone Repository

```bash
git clone https://github.com/BhavyaSolanki31/bhavya-solanki-portfolio.git
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

### Production Build

```bash
npm run build
```
